# DrawingBoard

A browser-based hand-tracked drawing and shape recognition tool built with MediaPipe Hands and the HTML5 Canvas.

Users draw in mid-air using their index finger, pause drawing by touching thumb and pinky, and receive a score and shape classification based on the accuracy of their drawing.
They can also just draw whatever they want with it. 

# Features
- Real-time hand tracking using MediaPipe Hands
- Index finger–based drawing in mid-air
- Thumb–pinky gesture to pause / resume drawing
- Persistent drawing layer (strokes are not erased when pausing)
- Optional white or camera-based background
- Shape fitting and recognition:
  - Circle 
  - Triangle
  - Square / Rectangle
  - Pentagon, Hexagon, Polygon
- Visual feedback and live status indicators
- Debug overlay showing hand landmarks and connections
